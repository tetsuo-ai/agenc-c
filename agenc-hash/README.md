# `agenc-hash`

> Planned: one fast non-crypto hash, SipHash with a per-process random key for hashmaps that see untrusted keys, and a PCG-style PRNG.

Layer 5 of the family build order. Not implemented yet. The scope and
ordering live in [../LIBRARIES.md](../LIBRARIES.md); the conventions are
set by [`agenc-str`](../agenc-str/) and [`agenc-arena`](../agenc-arena/).
